# Reel Script

From a messy idea to a 45–60 second script that sounds like you.

**Stage 1, outline:** it finds your actual take (asking up to three questions if needed),
names the predictable angles everyone else would post, checks any facts, and returns a
short backbone: thesis, angle, hook direction, beats, ending. You approve or edit it.

**Stage 2, script:** a spoken script written for the ear, with your emotion intact, one
concrete example, and no AI filler. Feedback like "too mechanical" or "lost my personality"
gets surgical revisions, not a rewrite.

Works for Instagram Reels, TikTok and YouTube Shorts.

## Install

**Claude Code:** copy the folder into your skills directory.

```bash
cp -r skills/reel-script ~/.claude/skills/      # all projects
# or: cp -r skills/reel-script .claude/skills/  # one project
```

**Claude apps:** zip the `reel-script` folder and upload it under Settings → Capabilities → Skills.
