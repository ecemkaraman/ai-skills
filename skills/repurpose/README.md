# Repurpose

Turn one piece of content into a genuinely different format, not the same words reshuffled.

Give it a script, article, post or transcript and a target (LinkedIn post, X thread,
carousel, caption, newsletter section). It keeps the core idea and evidence, then picks the
right entry point and structure for that channel. If a format doesn't fit, it says so
instead of forcing it. Every run ends with a short map of what else the piece could become.

## Install

**Claude Code:** copy the folder into your skills directory.

```bash
cp -r skills/repurpose ~/.claude/skills/      # all projects
# or: cp -r skills/repurpose .claude/skills/  # one project
```

**Claude apps:** zip the `repurpose` folder and upload it under Settings → Capabilities → Skills.

## Try it

- "Turn this script into a LinkedIn post"
- "Make a carousel from this article"
- "Repurpose this for X and my newsletter"
