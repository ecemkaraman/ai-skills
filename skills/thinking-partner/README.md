# Thinking Partner

A candid second opinion on a plan or decision, ending in a test you can run this week.

It names the assumptions your plan rests on, the decision you're really making, what you
know versus what you're hoping, and the weakest link. Then it gives you the cheapest way to
test that link. No flattery, no invented problems.

## Install

**Claude Code:** copy the folder into your skills directory.

```bash
cp -r skills/thinking-partner ~/.claude/skills/      # all projects
# or: cp -r skills/thinking-partner .claude/skills/  # one project
```

**Claude apps:** zip the `thinking-partner` folder and upload it under Settings → Capabilities → Skills.

## Try it

- "Stress-test this plan: <plan>"
- "Be honest, what am I missing?"
- "I keep going back and forth on <decision>"
