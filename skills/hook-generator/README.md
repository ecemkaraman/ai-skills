# Hook Generator

Better openings for videos, posts and articles: different angles first, then wording.

It reads your content, finds its strongest true asset, writes 8–12 hooks across distinct
psychological angles (belief flip, hidden mechanism, result first, diagnosis, and more),
cuts near-duplicates, and ranks them for reach, credibility and overall. Spoken hooks must
pass an ear test: a complete sentence you'd actually say, not a punchy fragment. Hooks that
overpromise get repaired or cut.

It also assesses, refines or compares hooks you already have.

## Install

**Claude Code:** copy the folder into your skills directory.

```bash
cp -r skills/hook-generator ~/.claude/skills/      # all projects
# or: cp -r skills/hook-generator .claude/skills/  # one project
```

**Claude apps:** zip the `hook-generator` folder and upload it under Customize → Skills (+ → Create skill → Upload a skill). Code execution must be on in Settings → Capabilities.

## Try it

- "Give me hooks for this script: <script>"
- "Check this hook: <hook>"
- "Which of these three openings is strongest?"
