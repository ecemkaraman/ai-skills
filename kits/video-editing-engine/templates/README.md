# Templates

Empty on purpose. After your first approved video, ask Claude to save the caption
style and title from it here, as files your animation engine can reuse:

- `captions.html` or `Captions.tsx`: the caption treatment, reading `brand.json`
- `title.html` or `Title.tsx`: the opening title
- `lower-third`, `key-term`, `callout`: add one only when you've used it twice

A small set of effects you trust beats new animation every time.
